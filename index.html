Array ဆိုတာ ဘာလဲ?

Array ဆိုတာ Variable တစ်ခုတည်းမှာ Data အများကြီးကို အစဉ်လိုက် သိမ်းဆည်းထားနိုင်တဲ့ Data Structure တစ်ခုဖြစ်ပါတယ်။ 

// Array တည်ဆောက်ခြင်း
const fruits = ["Apple", "Banana", "Orange"];
console.log(fruits[0]); // Output: "Apple"

ဘာလို့ Array Methods တွေသုံးတာလဲ?

Array ထဲက Data တွေကို အလွယ်တကူ ထည့်ဖို့၊ နှုတ်ဖို့၊ ရှာဖို့၊ ပြင်ဖို့ အတွက် JavaScript က အဆင်သင့်ရေးပေးထားတဲ့ Functions (Methods) တွေ ဖြစ်ပါတယ်။

Loops တွေအရှည်ကြီး ရေးစရာမလိုဘဲ Code ကို တိုတိုနဲ့ ရှင်းလင်းစေပါတယ်။

အရေးကြီးသော မှတ်သားဖွယ်

  • Mutating Methods: မူရင်း Array ကို ပြောင်းလဲသွားစေတဲ့ Method များ (ဥပမာ - push, pop)
  • Non-Mutating Methods: မူရင်း Array ကို မထိခိုက်ဘဲ Array အသစ်တစ်ခု ပြန်ထုတ်ပေးတဲ့ Method များ (ဥပမာ - map, filter)

အပိုင်း (၁)

အစ / အဆုံး ထည့်ခြင်း နှင့် ဖယ်ထုတ်ခြင်း

(push, pop, unshift, shift)

1. push() Method

Array ရဲ့ နောက်ဆုံး နေရာမှာ Data အသစ်တစ်ခု သို့မဟုတ် အများကြီး ထပ်ထည့်ချင်ရင် သုံးပါတယ်။

မှတ်ချက် - ၎င်းသည် မူရင်း Array ကို ပြောင်းလဲစေပါတယ်။ (Mutates)

push() - ဥပမာ


const numbers = [1, 2, 3];

// 4 ကို နောက်ဆုံးမှာ ထည့်မည်
numbers.push(4); 

console.log(numbers); 
// Output: [1, 2, 3, 4]

2. pop() Method

Array ရဲ့ နောက်ဆုံး မှာရှိတဲ့ Data တစ်ခုကို ဖယ်ထုတ်ပစ်ချင်ရင် သုံးပါတယ်။

ဖယ်ထုတ်လိုက်တဲ့ Data ကိုလည်း Return ပြန်ပေးပါတယ်။

pop() - ဥပမာ


const colors = ["Red", "Green", "Blue"];

// နောက်ဆုံးက Blue ကို ဖယ်ထုတ်မည်
const removedColor = colors.pop(); 

console.log(colors); // Output: ["Red", "Green"]
console.log(removedColor); // Output: "Blue"

3. unshift() Method

Array ရဲ့ အစဆုံး (ရှေ့ဆုံး) နေရာမှာ Data အသစ် ထပ်ထည့်ချင်ရင် သုံးပါတယ်။

Data တွေ အကုန်လုံး နောက်ကို တစ်နေရာစီ ရွေ့သွားရတဲ့အတွက် Performance အရ အနည်းငယ် နှေးနိုင်ပါတယ်။

unshift() - ဥပမာ


const animals = ["Dog", "Cat"];

// ရှေ့ဆုံးမှာ "Elephant" ထည့်မည်
animals.unshift("Elephant"); 

console.log(animals); 
// Output: ["Elephant", "Dog", "Cat"]

4. shift() Method

Array ရဲ့ အစဆုံး (ရှေ့ဆုံး) က Data တစ်ခုကို ဖယ်ထုတ်ချင်ရင် သုံးပါတယ်။

pop() လိုပါပဲ၊ ဖယ်ထုတ်လိုက်တဲ့ Data ကို Return ပြန်ပေးပါတယ်။

shift() - ဥပမာ


const cars = ["BMW", "Toyota", "Honda"];

// ရှေ့ဆုံးက BMW ကို ဖယ်ထုတ်မည်
const firstCar = cars.shift(); 

console.log(cars); // Output: ["Toyota", "Honda"]
console.log(firstCar); // Output: "BMW"

အပိုင်း (၂)

ပေါင်းခြင်း နှင့် ဖြတ်ထုတ်ခြင်း

(concat, join, slice, splice)

5. concat() Method

Array နှစ်ခု သို့မဟုတ် နှစ်ခုထက်ပိုသော Array များကို ပေါင်းပြီး Array အသစ်တစ်ခု ဖန်တီးပေးပါတယ်။

မူရင်း Array များကို မပြောင်းလဲစေပါ။ (Non-Mutating)

concat() - ဥပမာ


const arr1 = [1, 2];
const arr2 = [3, 4];

const combined = arr1.concat(arr2); 

console.log(combined); // Output: [1, 2, 3, 4]
console.log(arr1); // Output: [1, 2] (မပြောင်းလဲပါ)

6. join() Method

Array ထဲမှာရှိတဲ့ Data တွေအားလုံးကို ဆက်ပြီး String တစ်ခုတည်းအဖြစ် ပြောင်းလဲပေးပါတယ်။

ကြားထဲမှာ ဘာစာသားနဲ့ ဆက်မလဲ ဆိုတာကို သတ်မှတ်ပေးလို့ရပါတယ်။

join() - ဥပမာ


const words = ["Hello", "World", "JS"];

const sentence1 = words.join(" "); 
console.log(sentence1); // Output: "Hello World JS"

const sentence2 = words.join("-");
console.log(sentence2); // Output: "Hello-World-JS"

7. slice() Method

Array ထဲကနေ လိုချင်တဲ့ အပိုင်းကို ဖြတ်ယူပြီး Array အသစ်တစ်ခု ထုတ်ပေးပါတယ်။

စဖြတ်မည့် Index နှင့် ဆုံးမည့် Index (ထို Index မပါ) ကို ထည့်ပေးရပါတယ်။ မူရင်းကို မထိခိုက်ပါ။

slice() - ဥပမာ


const letters = ["A", "B", "C", "D", "E"];

// Index 1 ကနေ စဖြတ်မယ်၊ 3 မှာဆုံးမယ် (3 မပါဝင်ပါ)
const sliced = letters.slice(1, 3); 

console.log(sliced); // Output: ["B", "C"]
console.log(letters); // Output: ["A", "B", "C", "D", "E"]

8. splice() Method

Array ထဲက Data တွေကို ဖျက်တာ၊ အစားထိုးတာ၊ အသစ်ထည့်တာ တွေ အကုန်လုပ်လို့ရတဲ့ အစွမ်းထက် Method ဖြစ်ပါတယ်။

သတိပြုရန် - မူရင်း Array ကို တိုက်ရိုက် ပြောင်းလဲစေပါတယ်။ (Mutates)

splice() - ဥပမာ


const months = ["Jan", "March", "April"];

// Index 1 မှာ 0 ခုဖျက်ပြီး "Feb" ကို ထည့်မည်
months.splice(1, 0, "Feb");
console.log(months); // Output: ["Jan", "Feb", "March", "April"]

// Index 2 ကနေစပြီး 1 ခု ဖျက်မည်
months.splice(2, 1);
console.log(months); // Output: ["Jan", "Feb", "April"]

အပိုင်း (၃)

Data များ ရှာဖွေခြင်း

(indexOf, lastIndexOf, includes, find, findIndex)

9. indexOf() Method

Array ထဲမှာ ကိုယ်ရှာချင်တဲ့ Data ရှိ/မရှိ ရှာပေးပြီး၊ ရှိရင် သူရဲ့ ပထမဆုံး တွေ့တဲ့ Index Number ကို ပြန်ပေးပါတယ်။

မရှိရင်တော့ `-1` ကို ပြန်ပေးပါတယ်။

indexOf() - ဥပမာ


const names = ["Aung", "Kyaw", "Mya", "Kyaw"];

console.log(names.indexOf("Kyaw")); 
// Output: 1 (ပထမဆုံးတွေ့တဲ့ နေရာ)

console.log(names.indexOf("Su")); 
// Output: -1 (မရှိပါ)

10. lastIndexOf() Method

`indexOf()` နဲ့ တူတူပါပဲ၊ ဒါပေမယ့် သူက အနောက်ကနေ စရှာတာဖြစ်လို့ နောက်ဆုံးတွေ့တဲ့ Index Number ကို ပြန်ပေးပါတယ်။

lastIndexOf() - ဥပမာ


const names = ["Aung", "Kyaw", "Mya", "Kyaw"];

// အနောက်ကနေ စရှာမည်
console.log(names.lastIndexOf("Kyaw")); 
// Output: 3

11. includes() Method

Array ထဲမှာ ကိုယ်ရှာတဲ့ Data ပါသလား/မပါဘူးလား ဆိုတာကိုပဲ True သို့မဟုတ် False နဲ့ တိတိကျကျ ပြန်ပြောပေးပါတယ်။

Condition (if/else) တွေရေးတဲ့အခါ သုံးရအရမ်းကောင်းပါတယ်။

includes() - ဥပမာ


const fruits = ["Apple", "Mango", "Banana"];

console.log(fruits.includes("Mango")); 
// Output: true

console.log(fruits.includes("Grape")); 
// Output: false

12. find() Method

Array ထဲက Data တွေကို Function တစ်ခုနဲ့ စစ်ဆေးပြီး၊ သတ်မှတ်ချက်နဲ့ ကိုက်ညီတဲ့ ပထမဆုံး Data တစ်ခုတည်းကိုသာ ပြန်ထုတ်ပေးပါတယ်။

Object တွေပါတဲ့ Array တွေမှာ အများဆုံး သုံးပါတယ်။

find() - ဥပမာ


const numbers = [5, 12, 8, 130, 44];

// 10 ထက်ကြီးတဲ့ ပထမဆုံး ဂဏန်းကို ရှာမည်
const found = numbers.find(num => num > 10);

console.log(found); 
// Output: 12 (130, 44 တို့လည်းကြီးသော်လည်း ပထမဆုံးကိုသာယူသည်)

13. findIndex() Method

`find()` နဲ့ အလုပ်လုပ်ပုံတူပါတယ်။ ဒါပေမယ့် Data ကို ပြန်မပေးဘဲ အဲဒီ Data ရဲ့ Index Number ကိုသာ ပြန်ပေးပါတယ်။

findIndex() - ဥပမာ


const numbers = [5, 12, 8, 130, 44];

// 10 ထက်ကြီးတဲ့ ပထမဆုံး ဂဏန်းရဲ့ Index ကို ရှာမည်
const index = numbers.findIndex(num => num > 10);

console.log(index); 
// Output: 1 (12 ရဲ့ နေရာ Index ဖြစ်သည်)

အပိုင်း (၄)

ပတ်လည်လှည့်ခြင်း နှင့် ပြောင်းလဲခြင်း

(forEach, map, filter, reduce, some, every)

14. forEach() Method

Array ထဲမှာရှိတဲ့ Data တစ်ခုချင်းစီအတွက် Function တစ်ခုကို အစဉ်လိုက် ခေါ်သုံးပေးပါတယ်။ (for loop သုံးသလိုမျိုးပါပဲ)

သူက ဘာမှ Return ပြန်မပေးပါဘူး (undefined)။ Action တစ်ခုခု လုပ်ဖို့အတွက်သာ သုံးပါတယ်။

forEach() - ဥပမာ


const students = ["Aung", "Mya", "Hla"];

students.forEach((student, index) => {
    console.log(`${index + 1}: ${student}`);
});
// Output: 
// 1: Aung
// 2: Mya
// 3: Hla

15. map() Method

Array ထဲက Data တွေကို Function နဲ့ ပြုပြင်ပြောင်းလဲပြီး၊ ရလာတဲ့ ရလဒ်တွေနဲ့ Array အသစ်တစ်ခု ဖန်တီးပေးပါတယ်။

React လို Framework တွေမှာ UI Render လုပ်ဖို့ အသုံးအများဆုံး Method ဖြစ်ပါတယ်။

map() - ဥပမာ


const numbers = [1, 2, 3, 4];

// ဂဏန်းတိုင်းကို ၂ ဆ တိုးမည်
const doubled = numbers.map(num => num * 2);

console.log(doubled); // Output: [2, 4, 6, 8]
console.log(numbers); // မူရင်း Array မပြောင်းလဲပါ

16. filter() Method

ကိုယ်သတ်မှတ်ထားတဲ့ Condition (အခြေအနေ) နဲ့ ကိုက်ညီတဲ့ (True ဖြစ်တဲ့) Data တွေကိုပဲ စစ်ထုတ်ပြီး Array အသစ် ဖန်တီးပေးပါတယ်။

filter() - ဥပမာ


const ages = [15, 22, 18, 10, 30];

// အသက် ၁၈ နှစ်နှင့်အထက်များကိုသာ စစ်ထုတ်မည်
const adults = ages.filter(age => age >= 18);

console.log(adults); 
// Output: [22, 18, 30]

17. reduce() Method

Array ထဲက Data တွေအားလုံးကို တွက်ချက်ပြီး တန်ဖိုး တစ်ခုတည်း (Single Value) ရအောင် လျှော့ချ (Reduce) ပေးပါတယ်။

ဥပမာ - ကိန်းဂဏန်းတွေ အားလုံးပေါင်းချင်တဲ့အခါ သုံးပါတယ်။

reduce() - ဥပမာ


const numbers = [10, 20, 30];

// အားလုံးကို ပေါင်းမည် (Total)
const sum = numbers.reduce((total, current) => {
    return total + current;
}, 0); // 0 သည် စတင်မည့် တန်ဖိုးဖြစ်သည်

console.log(sum); 
// Output: 60

18. some() Method

Array ထဲမှာ ကိုယ်သတ်မှတ်ထားတဲ့ Condition နဲ့ ကိုက်ညီတဲ့ Data အနည်းဆုံး တစ်ခု ရှိသလား ဆိုတာကို စစ်ပေးပါတယ်။ (True / False ပြန်ပေးပါတယ်)

some() - ဥပမာ


const scores = [45, 50, 39, 80];

// အမှတ် ၈၀ အထက် အနည်းဆုံး တစ်ယောက်ရှိသလား?
const hasDistinction = scores.some(score => score >= 80);

console.log(hasDistinction); 
// Output: true

19. every() Method

Array ထဲက Data အားလုံး ကိုယ်သတ်မှတ်ထားတဲ့ Condition နဲ့ ကိုက်ညီမှသာ True ပြန်ပေးပါတယ်။ တစ်ခုလေး မှားတာနဲ့ False ပြန်ပေးပါတယ်။

every() - ဥပမာ


const ages = [20, 25, 30, 15];

// အားလုံး အသက် ၁၈ နှစ်အထက် ဖြစ်သလား?
const allAdults = ages.every(age => age >= 18);

console.log(allAdults); 
// Output: false (15 ပါနေသောကြောင့်)

အပိုင်း (၅)

စီစဉ်ခြင်း (Sorting & Reversing)


20. sort() Method

Array ကို အက္ခရာစဉ် (သို့) ကိန်းဂဏန်း အစဉ်လိုက် စီပေးပါတယ်။ (Mutates)


const fruits = ["Banana", "Apple", "Orange"];
fruits.sort();
console.log(fruits); // Output: ["Apple", "Banana", "Orange"]

21. reverse() Method

Array ထဲက Data တွေကို လက်ရှိ အစဉ်လိုက်ကနေ ပြောင်းပြန် (Reverse) လှန်ပစ်ပါတယ်။ (Mutates)


const numbers = [1, 2, 3, 4, 5];
numbers.reverse();

console.log(numbers); 
// Output: [5, 4, 3, 2, 1]
